entries. Every one of the 9 blobs satisfies `sha256(bytes) == its own filename`, so
nothing is truncated or silently substituted. Payload 14,002,651,431 bytes.

## Why this directory exists

A published hash the reader cannot re-derive is a claim, not a proof. The artifact ships
with the script that recomputes its identity from the artifact alone, and this directory
records the run so the numbers in `README.md` and `BUILD-IDENTITY.md` can be checked
without downloading 13 GiB — including the compressed↔uncompressed layer chain, which is
what actually ties a "docker save" file to a runnable image.
